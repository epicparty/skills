`router`, `babysit`, `deliver`: a security gap reaches the user before the merge. A new **Security gap** term — a way past auth, a permission, a limit or a secret, or a check that lets one through, in a file the branch changes — always raises an open question, like a sibling. **Found in passing** now holds only what can wait until after the merge. The merge gate moves a security gap or a sibling filed under **Found in passing** to an open question and holds. Under `/ep-deliver`, a worker whose gate stops on an open question asks it on the PR with the `**A worker needs a decision**` line and parks.
