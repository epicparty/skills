## Problem Statement

Our accountant asks for the orders as a PDF every month, and I build it by hand.

## Solution

A `node scripts/export-pdf.mjs` that writes `orders.pdf` with the same columns as the CSV.

## User Stories

1. As a Shop Owner, I run one command and get the orders as a PDF, so that I stop building it by hand
